КОРОЛЕВСКАЯ АРЕНА — PWA пакет

Файлы:
- index.html — игра
- manifest.webmanifest — имя, иконки и режим установки
- service-worker.js — кэширование для повторного/офлайн запуска
- icon-192.png и icon-512.png — иконки приложения

Публикация:
1. Загрузить ВСЕ файлы и сохранить структуру папки на HTTPS-хостинге.
2. В корне сайта должен открываться index.html.
3. На iPhone открыть HTTPS-ссылку в Safari.
4. Нажать Поделиться → На экран «Домой» → включить «Открывать как веб-приложение» (если этот переключатель доступен) → Добавить.

Важно:
- Service Worker работает только на HTTPS (или localhost).
- Первый запуск должен быть онлайн, чтобы файлы закэшировались.
- Офлайн-работа и сохранение прогресса нужно проверить на устройстве после публикации.
